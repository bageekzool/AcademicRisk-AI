
# AcademicRisk AI

## Project Title

Makine Öğrenmesi Tabanlı Açıklanabilir Öğrenci
Akademik Risk Analizi ve Erken Uyarı Sistemi

## Project Description

AcademicRisk AI is a machine learning research prototype
designed to predict student academic outcomes.

The system predicts three classes:

- Dropout
- Enrolled
- Graduate

## Dataset

UCI Machine Learning Repository
Predict Students' Dropout and Academic Success
Dataset ID: 697

## Machine Learning Models

- Logistic Regression
- Random Forest
- XGBoost

## Prediction Stages

1. Enrollment: Prediction using enrollment information.
2. First Semester: Prediction using enrollment and
   first-semester academic information.

## Technologies

- Python 3.11
- pandas and NumPy
- scikit-learn
- XGBoost
- SHAP
- Streamlit
- Plotly
- pytest

## Current Development Status

Phase 1: Environment and project setup.

## Installation

Create and activate a Python virtual environment,
then install project dependencies:

```powershell
python -m pip install -r requirements.txt
```

## Disclaimer

This project is an academic research prototype.
Predictions should not be used as the sole basis
for decisions about individual students.
